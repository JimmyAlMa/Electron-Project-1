# First Electron Project - Desktop Text Editor

This is my first desktop application built to learn Electron.js and Node.js. It features a simple Text Editor with the following capabilities:

* Open File: Open text files (.txt).
* Save File: Save text content directly to local files.
* Real-time Character Counter: Count characters instantly as you type.

---

## How to Run

```bash
# 1. Install dependencies
npm install

# 2. Start the application
npm start
